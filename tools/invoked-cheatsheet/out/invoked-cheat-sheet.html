Golden rules

  1. Baybarron: say SKIP to the banish unless you've picked a target
  2. Madness needs a spare card to discard. Keep one
  3. Oceanus goes in the Extra Monster Zone
  4. Before any Link: is there a free zone?
  5. Read both GYs + banishment before Invocation
  6. Discard order: dead copies (2nd Meltdown, used Sword) → Fuwalos → Imperm → Crossout → Ghost Belle. KEEP Maxx C, Ash, Super Poly, Droll, Nibiru
  7. Mechaba: keep 1 monster + 1 Spell/Trap in hand if you can

Discard order (Madness, Mechaba, Super Poly, Spenta)

  1. Dead copies: 2nd Meltdown, a Sword when another is set, Sacred Spirit Sword after you've used one
  2. Mulcharmy Fuwalos (dead once you control cards)
  3. Infinite Impermanence, unless you'll set it
  4. Crossout Designator
  5. Ghost Belle

Keep: Maxx "C", Ash, Super Poly, Droll, Nibiru, Ghost Ogre

Aleister + FIRE/WIND

Sourced: Taffy (MDM)

AleisterFIRE/WIND: Ash, Droll, Fuwalos, Zoroa+1 spare card

Get Sorath

  1. Normal Summon Aleister → search Invocation
  2. Link Aleister → Artemis
  3. Invocation: Aleister (GY) + FIRE/WIND (hand) → Sorath
  4. Invocation GY: add the banished Aleister
  5. Discard Aleister on Sorath (+1000)
  6. Sorath: revive Aleister

Crowley into Baybarron

  1. Link Aleister + Artemis → Endymion, equip Artemis
  2. Artemis: search Crowley (it summons itself)
  3. Crowley: Crowley + Endymion → Baybarron

Finish

  1. Link Sorath + Baybarron → Madness
  2. Sorath GY: Sorath + Aleister → Mechaba
  3. Madness: discard spare → search Invocation
  4. Invocation: Madness + Crowley (GY) → Oceanus (Extra Monster Zone)
End boardOceanus (EMZ) · Mechaba · Virakam · set Sword

Going 2nd: finishers

Built from card text · add to the end of any line

Use whatever you have left

Remove her blocker

  1. Sword in hand: Aleister + a Fusion (both banished) → Omega → banish her monster
  2. Super Poly: Madness (counts as Aleister) + her monster → Fusion by her Attribute: LIGHT/EARTH Baybarron, WIND Raidjin, FIRE Sorath, DARK/WATER Oceanus
  3. Do Super Poly BEFORE Invocation uses Madness. Invocation can still use Madness from the GY

More damage

  1. Aleister in hand: discard during battle → a Fusion gains 1000
  2. Oceanus in GY: banish it → one Fusion can attack directly
  3. Little Knight: SKIP its banish or you can't attack directly

Attack values

  1. Aeon 3800 · Oceanus 3000 · Baronne 3000 · Omega 2800 · Mechaba 2500 · Baybarron 2450
  2. Raidjin 2200 · Madness 1800 · Sorath 1600 · Little Knight 1600 · Virakam 1000
